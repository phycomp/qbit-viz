# qbit-viz

Quantum bit visualization skill — 2/3 qubit logic gates, Bloch sphere rendering, state evolution, and interactive demos using Qiskit + Aer.

## What it does

- Logic gate reference (single & multi-qubit)
- Bloch sphere visualization (Qiskit + PyVista)
- Quantum state evolution and entanglement
- Aer simulator integration
- Streamlit interactive demos
- Code templates (Bell, GHZ states)

## Install

```bash
npx skills add phycomp/qbit-viz@qbit-viz -g -y
```
